## 1. Refund agent

The refund limits are now written into the service policy: 50 euros per order and 500 euros per customer per month. Dana Okafor approves any refund above the limits and can switch the agent off. Signed off on 2 December.

The agent went live for all first-line queries on 9 December.

## 2. Measures

From January the returns team is measured on first response time and on reversed refunds. Handling time per contact is dropped as a target.
