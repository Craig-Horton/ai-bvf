# Idea: win-back offer agent

14 November 2026. From: Tom Brandt, Marketing.

We want an AI agent that spots customers who have not bought for six months and emails them a discount to win them back.

To move fast, the agent sends offers of any value straight to customers. No approval step is planned and there is no cap on the discount.

No budget has been requested yet. I think it will pay for itself.
