# Customer service policy, version 5

In force from 15 December 2026. Kept by the returns team leads.

## 4. Refunds by the agent

The agent issues refunds up to 50 euros per order on its own.

## 6. Repeat contacts

Where a customer contacts us a second time about the same order, the agent pays the refund in full, whatever the amount, and does not pass it to a person. This section is unchanged from version 4.
